# 📖 Manga & Manhwa Reader (Flutter / Android)

Мобильное приложение-читалка манги, манхвы и маньхуа в стиле **shadcn dark zinc** (матовое стекло, тонкие границы 1px, скругления, палитра `#09090b`).

---

## 🚀 Реализованный функционал

### 1. Умная фильтрация и исключения (Exclusion Filters)
- **Трёхпозиционные статусы (Tri-state):**
  - ⚪ **Нейтрально:** показывать всё
  - 🟢 **Включить:** показывать только этот статус
  - 🔴 **Исключить (🚫):** **ПОЛНОСТЬЮ СКРЫТЬ** из каталога то, что вы отметили как **«Читаю»** или **«Прочитано»**.
- **Быстрые кнопки в 1 тап:** переключатели прямо над каталогом: `🚫 Скрыть прочитанное`, `🚫 Скрыть читаю`, `🇰🇷 Манхва`.

### 2. Фильтр типов произведений
- 🇰🇷 **Манхва** (Корейские цветные вебтуны)
- 🇯🇵 **Манга** (Японские черно-белые комиксы)
- 🇨🇳 **Маньхуа** (Китайские вебтуны)

### 3. Возрастной рейтинг и цензура
- **0+ (Safe)** — без возрастных ограничений
- **16+ (Suggestive)** — подростковый контент
- **18+ (Erotica)** — взрослый контент (включается/отключается в модалке фильтра)

### 4. Фильтр по жанрам
15 популярных жанров: Экшен, Приключения, Комедия, Драма, Фэнтези, Исекай, Романтика, Повседневность, Ужасы, Боевые искусства, Детектив, Психология, Фантастика, Сверхъестественное, Триллер.

### 5. Режимы чтения
- **Webtoon Reader (манхва/маньхуа):** бесшовный вертикальный скролл на 120 кадров/сек без стыков между фреймами с кешированием.
- **Paged Reader (манга):** постраничный режим справа-налево (RTL).
- **Матовые оверлеи:** меню скрывается по тапу, не отвлекая от чтения.

### 6. Источник контента
- Интегрирован **MangaDex API** с фильтром русского языка (`availableTranslatedLanguage[]=ru`).
- Предусмотрен встроенный офлайн-кэш и демо-каталог на случай отсутствия сети.

## 📱 Как запустить на телефоне (Android)

1. **Скачать Flutter SDK:**
   * Распаковать архив Flutter SDK в удобную папку (например, `C:\flutter`).
   * Добавить путь `C:\flutter\bin` в переменную окружения `PATH`.
2. **Включить на телефоне режим разработчика:**
   * На Android: *Настройки -> О телефоне -> нажать 7 раз на «Номер сборки»*.
   * В разделе *Для разработчиков* включить **«Отладка по USB»** и подключить телефон проводом к ПК.
3. **Запуск приложения:**
   ```bash
   cd D:\Progs\OSPanel\home\manga-reader-app
   flutter run
   ```
4. **Сборка готового APK-файла:**
   ```bash
   flutter build apk --release
   ```
   Готовый установочный файл появится в `build/app/outputs/flutter-apk/app-release.apk` — его можно сразу скинуть на телефон и установить.
